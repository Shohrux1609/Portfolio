Student Performance KPI Analysis

**Overview**
This project presents a data analysis and KPI evaluation of student performance using Python.
The goal is to explore how different factors such as gender, parental education, and test preparation influence academic results.

The analysis follows a typical data analyst workflow:
data exploration
KPI calculation
group comparison
visualization of insights

**Dataset**
The dataset contains 1000 student records with the following features:
Gender
Race/Ethnicity
Parental Level of Education
Lunch Type
Test Preparation Course
Math Score
Reading Score
Writing Score

**Tools**
Python
Pandas
Matplotlib
Seaborn

**Key Performance Indicators (KPIs)**

The following KPIs were calculated:
Average Score (across math, reading, writing)
Pass Rate (based on average score threshold)
Performance by Gender
Impact of Test Preparation
Impact of Parental Education
Correlation between subjects

**Analysis Performed**
1. Data Preparation
Loaded dataset using Pandas
Verified structure and data types
Created derived metrics (average score, pass indicator)

2. KPI Analysis
Calculated overall student performance
Compared performance across different groups
Evaluated the effect of external factors

4. Data Visualization
Visualizations were created to support analysis:
Score distributions
Group comparisons (bar charts)
Correlation heatmap
KPI-based insights

**Key Insights**
Students who completed test preparation courses tend to have higher average scores
There are noticeable performance differences across demographic groups
Scores in math, reading, and writing are positively correlated
Parental education level shows a measurable impact on student performance
